# ABB Bank Website Recreation

### Overview

This project is a frontend recreation of the official website of the Azerbaijan International Bank (ABB). The goal is to showcase web development skills by mimicking a real banking website, focusing on responsive design and interactive financial tools. It's a static site with dynamic elements powered by JavaScript, including advanced calculators for loans, mortgages, and deposits.

The project emphasizes modern web practices: HTML for structure, CSS for basic styling, and Tailwind CSS for the majority of the UI components, ensuring a clean, utility-first approach. Extensive JavaScript handles complex banking computations, simulating real-world financial scenarios without any backend integration.

### Features:

**Responsive Design:** Fully mobile-friendly layout using TailwindCSS     classes for grids, flexbox, and media queries.

**Banking Calculators:** Interactive JS-based tools for:
-Loan calculations (interest rates, repayment schedules, total costs).
-Mortgage estimators (amortization tables, down payment impacts).
-Deposit simulators (compound interest, maturity values).

**Static Pages:** Recreations of key sections like home, services, about,contact, and product pages.

**Custom Animations and Interactions:** Smooth transitions, form validations, and dynamic content updates via vanilla JavaScript.

**Accessibility:** Basic ARIA attributes and semantic HTML for better user experience.

### Technologies Used:

**HTML5:** Core structure and semantics.

**CSS3:** Minimal custom styles for overrides.

**Tailwind CSS:** Primary styling framework (v3.x) for rapid development and consistent design.

**JavaScript (ES6+):** Handles all logic, including mathematical computations for financial models (e.g., formulas for APR, EMI, compound interest).

**No Dependencies:** Pure vanilla setup; no external libraries like React or jQuery to keep it lightweight.
